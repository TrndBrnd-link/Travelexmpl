# رحلاتي — تطبيق ويب لمقارنة وحجز رحلات الطيران

تطبيق ويب متجاوب (mobile-first) بدون أي خادم أو API. كل البيانات تُقرأ مباشرة من ملفات JSON داخل المستودع، وكل الصور تُقرأ من مجلد `assets/`. يمكن رفعه كما هو على **GitHub Pages** ويعمل فورًا.

## هيكلية المشروع

```
├── index.html              # هيكل الصفحة (RTL بالكامل)
├── css/
│   └── style.css           # التصميم، التوكنز، الأنيميشن
├── js/
│   └── app.js               # منطق التطبيق: البحث، الفرز، الحفظ، واتساب
├── data/                    # "قاعدة البيانات" — ملفات JSON منظمة ومترابطة
│   ├── cities.json          # المدن (نقاط الانطلاق والوجهات)
│   ├── airlines.json        # شركات الطيران
│   ├── agencies.json        # مكاتب السفر ورقم واتساب كل مكتب
│   └── flights.json         # الرحلات، وكل رحلة تحتوي مصفوفة "offers" من المكاتب
└── assets/
    ├── destinations/*.svg   # صور توضيحية أصلية لكل مدينة
    └── airlines/*.svg       # شعارات مبسطة (غير تجارية) لكل شركة طيران
```

## بنية البيانات (schema)

البيانات مُطبَّعة (normalized) وتُربط بالمعرّفات (id) بدل تكرار المعلومات:

- **`cities.json`** → `{ code, name_ar, name_en, country_ar, type, image, trending }`
- **`airlines.json`** → `{ id, name_ar, code, badge_color, logo }`
- **`agencies.json`** → `{ id, name_ar, city_ar, rating, reviews, verified, whatsapp, response_time_ar }`
- **`flights.json`** → `{ id, airline_id, from, to, date, departure_time, arrival_time, duration_minutes, stops, cabin_class, offers: [{ agency_id, price, currency, seats_left }] }`

كل رحلة قد تُعرض من أكثر من مكتب سفر بسعر مختلف (`offers`)، والتطبيق يقارن هذه العروض تلقائيًا ويرتبها.

## كيف تضيف بيانات جديدة

- **مدينة جديدة:** أضف كائن جديد في `cities.json` وصورة SVG/PNG مطابقة داخل `assets/destinations/`.
- **رحلة جديدة:** أضف كائن في `flights.json` مع `airline_id` موجود في `airlines.json`، وعروض (`offers`) بمعرّفات مكاتب موجودة في `agencies.json`.
- **مكتب سفر جديد:** أضف كائن في `agencies.json` مع رقم `whatsapp` بصيغة دولية بدون علامة + (مثال: `9647xxxxxxxx`).

## آلية الحجز

لا يوجد نموذج دفع أو checkout داخل التطبيق. بعد اختيار الرحلة والعرض المناسب، يضغط المستخدم على زر **"احجز الآن"** فيُفتح واتساب مباشرة مع المكتب المعني ورسالة معبّأة تلقائيًا بتفاصيل الرحلة (شركة الطيران، التاريخ، عدد المسافرين، الدرجة، السعر، رمز الرحلة). تكتمل عملية الحجز والدفع عبر تواصل مباشر بين المستخدم والمكتب.

## صفحة "حجوزاتي"

بدلاً من صفحة "حسابي" (تمت إزالتها)، توجد لوحة جانبية "حجوزاتي" تُفتح من زر في الشريط العلوي أو السفلي، وتعرض الرحلات التي حفظها المستخدم (عبر أيقونة القلب) محليًا في المتصفح (`localStorage`) — دون الحاجة لحساب أو تسجيل دخول.

## النشر

ارفع المجلد كما هو إلى مستودع GitHub وفعّل GitHub Pages من إعدادات المستودع (Settings → Pages → Deploy from branch). لا حاجة لأي بناء (build) أو تبعيات خارجية باستثناء خط Google Fonts.
